# 🌤️ Live Weather Forecast

A modern, responsive, and feature-packed atmospheric intelligence web application built with **React 19**, **Vite**, and **Tailwind CSS**, powered by the **Open-Meteo Global Meteorological API**.

---

## ✨ Features

- 🔍 **Instant City Search & Autocomplete:** Search any city, state, or country worldwide with live suggestions.
- 📍 **Live Geolocation ("My Location"):** One-click GPS location detection to get your local weather instantly.
- 🌍 **Live Global Weather Across Countries:** Real-time atmospheric readings for major global cities (Lahore, Karachi, Dubai, London, New York, Tokyo, Paris, Istanbul, Toronto, etc.).
- 🌡️ **Dual Temperature Units:** Seamless 1-click toggle between Celsius (**°C**) and Fahrenheit (**°F**).
- 🌐 **Bilingual Interface:** Full bilingual support with seamless switching between **English** and **اردو (Urdu)**.
- 🕒 **24-Hour Hourly Forecast:** Scrollable 24-hour carousel with temperatures, weather icons, and precipitation chances.
- 📅 **7-Day Daily Forecast:** Complete 7-day forecast with visual temperature gradient range bars.
- 📊 **Detailed Weather Metrics:**
  - 💧 **Humidity** with comfort indicators
  - 💨 **Wind Speed & Direction** with live compass tracking
  - ☀️ **UV Index** with safety advisories (Low to Extreme)
  - ⏲️ **Atmospheric Surface Pressure** (hPa)
  - 👁️ **Cloud Cover & Visibility**
- 🌅 **Daylight & Sun Path Tracker:** Visual daylight arc progress tracking sunrise and sunset times.
- 🍃 **Air Quality Index (AQI):** Comprehensive pollutant breakdown (PM2.5, PM10, Ozone, Carbon Monoxide) with health guidance.
- ⚠️ **Proactive Weather Alerts:** Real-time warnings for rain, heat waves, extreme cold, or high winds.
- ⭐ **Pinned / Favorite Cities:** Save your favorite cities locally for instant 1-click access.
- 🎨 **Dynamic Atmosphere Themes:** Adaptive glassmorphic UI that automatically matches current weather conditions (Sunny, Clear Night, Rain, Thunderstorm, Overcast, Snow).

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Weather API:** [Open-Meteo](https://open-meteo.com/) (100% Free, No API key required)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bashirahmed-Developer/Live-Weather-Forecast-.git
   cd Live-Weather-Forecast-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:5173/
   ```

---

## 📦 Production Build

To build the application for production:

```bash
npm run build
```

The optimized static assets will be output in the `dist/` directory, ready to deploy to **Vercel**, **Netlify**, or **GitHub Pages**.
